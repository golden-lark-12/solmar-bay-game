Solmar Bay is an open-world crime game in the spirit of GTA 6: a sun-soaked coastal city to explore on foot and by car, with traffic, pedestrians, cars to steal, a wanted level and police, missions and a story, combat, a HUD with a minimap, a start screen and a save. It runs offline in a desktop browser from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
